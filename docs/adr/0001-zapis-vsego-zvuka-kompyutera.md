# 0001. Запись созвона: весь звук компьютера через loopback в скрытом окне

## Контекст
Нужно писать собеседников из любой программы (Zoom, Teams, Telegram, Meet, вебинар) на Mac и Windows одним кодом.

## Решение
Звук компьютера берётся через `getDisplayMedia` с `audio: 'loopback'`: главный процесс отвечает на запрос обработчиком `setDisplayMediaRequestHandler` только для окна записи, видео-дорожки сразу останавливаются. Записывает то же скрытое окно, которое показывает панель: `MediaRecorder` на каждую дорожку, куски по 10 с в существующий протокол `/recordings`. Источник всегда «Весь звук компьютера»; запись одной программы в эту версию не входит (пользователь выбрал «Везде только весь звук»).

## Почему
- Loopback в Electron один и тот же на Mac (ScreenCaptureKit) и Windows (WASAPI): не нужно писать два нативных захватчика.
- Скрытое окно с `MediaRecorder` повторяет решённую задачу расширения для Chrome (куски, повторы, `lost`), протокол движка не меняется.
- Одно окно вместо пары «окно записи + окно панели» — меньше сообщений между ними.
- Отвергнуто: запись одной программы. На Windows это process loopback (нужна 10 2004+ и запасной путь), на Mac отдельный нативный код; цена высока, а «весь звук» закрывает основной сценарий.
- Отвергнуто: нативный захват в отдельном процессе. Больше кода, две платформы, чужая сборка.

## Последствия
- В запись попадает всё, что играет на компьютере: музыка и уведомления, а не только звонок. Закрытие Zoom запись не прерывает.
- На Mac нужно разрешение «Запись экрана и системного звука», хотя видео не пишется; без него записи нет, поэтому есть окно-объяснение.
- Без наушников микрофон слышит динамики; повторы убирает сведение дорожек, и это надо проверять на реальной записи.
- Windows-путь написан, но на этом Mac не запускался.
- Выбор одной программы потом придётся добавлять поверх, не ломая «весь звук».
