# 0002. Дорожка `system` и источник `system` в движке наравне с `tab`

## Контекст
Двухдорожечное сведение («Я» из микрофона, собеседники по голосам) в движке работало только для встреч из Chrome: источник `meet`, дорожка `tab`.

## Решение
В движке появляются источник записи `system` (подпись «Call»/«Созвон») и дорожка `system`. Везде, где работает `tab`, `system` обращается так же: сведение, повторная разметка говорящих, метка дорожки у слов. Необязательное имя программы `app` хранится в расшифровке.

## Почему
- Дорожка собеседников устроена одинаково, как бы она ни была получена; общий путь даёт готовые `drop_echo` и разбиение по голосам без второй копии логики.
- Отвергнуто: выдавать запись созвона за `meet`. Тогда в библиотеке нельзя отличить Meet из Chrome от записи всего звука, и подписи, и поиск по источнику врут.
- Отвергнуто: отдельная ветка слияния для `system`. Два места, которые расходятся при следующей правке.

## Последствия
- Новые значения попадают в `transcript.json` на диске пользователей. Откатить имя `system` потом нельзя без миграции.
- Каждое новое место в движке, которое знает про `tab`, теперь обязано знать и про `system`; забытое место молча сломает только записи созвонов.
- Расшифровка запоминает `app` и `lost`; повторная расшифровка должна их сохранять.
