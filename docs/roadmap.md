# Тиць: роадмап

2026-11-08, версия 0.4.0. Порядок — по важности; размер: S — день, M — несколько дней, L — неделя и больше.
Задачи заведены как issues на GitHub (designmakc/tyts), версии — как milestones.

## 0.5 — Скриншоты (новое)

Сейчас снимок экрана есть только как вход для перевода и чтения (`snipKey`, `ms-screenclip:` на Windows). Нужен снимок как самостоятельный инструмент.

| # | Задача | Размер |
|---|---|---|
| #5 | **Снимок области, окна или всего экрана** своей клавишей (по умолчанию пустая), пункт в трее и в меню на одной клавише. Готовый снимок — в буфер обмена (картинкой). Windows и Mac | M |
| #6 | **Сохранить в папку**: выбор папки в настройках, имя `<дата время>.png`; переключатель «в буфер / в папку / оба». Тост «Скопировано» / «Сохранено» с кнопкой «Показать в папке» | S |
| #7 | **Редактор снимка**: окно сразу после снимка (можно отключить). Инструменты: стрелка, прямоугольник, выделение цветом (полупрозрачный маркер), текст. 5–6 цветов, толщина, отменить/повторить (Ctrl+Z / Ctrl+Shift+Z). Кнопки: Копировать, Сохранить, Перевести текст, Прочитать вслух. Рисовать на `<canvas>`, без новых библиотек | L |
| #8 | Справка и лендинг: новая функция на страницах, в «Клавишах», в поиске настроек, на трёх языках | S |

Позже, если попросят: размытие (скрыть личное), нумерованные метки, обрезка, снимок с задержкой, история снимков.
