# Что взять в Тиць из Granola

2026-11-10. Разбиралась Granola 7.749.1 для Mac (Electron, образ 272 МБ) инструментом REA: тексты интерфейса, фоновый код и список встроенных помощников. Приложение не запускалось, поэтому часть функций может быть выключена переключателями или доступна только на платных тарифах. Сравнение — с Tyts 0.5.1 по `src/i18n/en.ts`.

Granola — заметки по созвонам плюс голосовой набор. Расшифровка по умолчанию идёт в облаке (Deepgram, AssemblyAI); режим «на устройстве» есть, но только английский и «чуть менее точный». У Тиць всё локально и на всех языках — это наше отличие, его стоит писать на лендинге.

Размер: S — день, M — несколько дней, L — неделя и больше.

## Дёшево и полезно (делать первыми)

| Что | Как у Granola | Что у нас сейчас | Размер |
|---|---|---|---|
| **«Вы ещё здесь?»** | Если долго тишина: «We haven't heard anything in a while so we will stop transcribing shortly», отсчёт 60 секунд, кнопка «продолжить» | Автостоп есть только у записи, начатой самой (микрофон свободен 20 с). Забытая ручная запись идёт до конца диска | S |
| **Не спрашивать про звонок в этих программах** | «Don't notify me when a call is detected in these apps» — список со снятыми галочками | Список программ звонков зашит (`callapps.ts`), выключить одну нельзя | S |
| **Готовые вопросы к записи** | «Recipes»: сохранённые вопросы, поделены на «до / во время / после встречи»: «Какие решения приняты?», «Кому я забыл ответить?», «Какие слова я повторяю?» | Вопросы к записи есть (`ask.ts`), готовых кнопок нет | S |
| **«Короче» и «Подробнее» у итога** | Кнопки «Make notes shorter / longer» | Только «Сделать заново» и шаблоны | S |
| **Звук начала и конца диктовки, приглушить остальной звук** | «Play sounds when voice typing starts and stops», «Mute system audio while voice typing» | Щелчок есть только у исправления раскладки. Проверить, что у диктовки | S |
| **Скрыть личные номера перед итогом** | Вычёркивает из расшифровки номера карт и документов до того, как делать итог | Нет. Делается простыми правилами, без модели; подходит правилу приватности | S–M |

## Дороже, но в духе Тиць

| Что | Как у Granola | Размер |
|---|---|---|
| **Задачи из созвонов одним списком** | Пункты «что сделать» из всех итогов собираются на отдельной странице с галочками; у каждого — «полезно / убрать» | M |
| **Имена и термины с экрана для диктовки** | «Uses text from the app you're using to help spell names correctly». У нас чтение экрана уже есть (`ocr.ts`, `uia.ts`) | M |
| **Снимки чужого экрана сами** | Когда собеседник показывает экран, снимок делается сам (сначала спрашивает, какое окно). У нас снимок только по кнопке | M |
| **Календарь** | Название встречи из календаря, напоминание за минуту до начала, ближайшая встреча в строке меню. На Mac читает системный календарь без входа в аккаунт. У нас это отложенное решение из `meetings-autostart-plan.md` | M–L |
| **Доступ к записям для ИИ-помощников** | Команда `granola` и MCP: Claude Code и другие читают заметки. У нас можно сделать локально, только чтение, выключено по умолчанию | M |
| **Точные имена говорящих** | Читает окно Zoom, Meet и Teams и видит, кто сейчас говорит. У нас имена угадываются по обращениям (`addressed.ts`). Хрупко: ломается при каждом обновлении этих программ | L |

## Что подтвердилось (у нас уже так)

Вопрос ко всем записям сразу (`ask.ts`), «Запомнить это исправление?» у диктовки, автозапуск по занятому микрофону со списком программ, вопрос «Записать?», фраза о записи для чата, запись без бота в звонке, свой словарь имён и терминов, шаблоны итога, загрузка аудиофайла, предупреждение при выходе во время записи, слова во время записи, локальный Parakeet для диктовки. Granola пришла к тем же решениям — значит, направление верное.

## Не брать

Отклонено владельцем 2026-11-10: пауза музыки при начале созвона; предупреждения про закрытую крышку и Bluetooth-микрофон; черновик письма после созвона; «это не записывай»; повтор диктовки из сохранённого звука; стиль письма по типу программы; корзина на 30 дней. Остальное ушло в `granola-plan.md` и роадмап.

| Что | Почему |
|---|---|
| Аккаунт, тарифы, рабочие пространства, общий доступ по ссылке, «вики компании» | Тиць без учётной записи и без облака |
| Salesforce, HubSpot, Notion, Slack, Zapier, отправка писем через Gmail | Отправка наружу; у нас только текст в буфер |
| Водяной знак на видео (виртуальная камера) и письма гостям о записи | Системное расширение, права администратора; согласие у нас решается фразой для чата |
| Помощник «со своим компьютером», Telegram-бот, оповещения на телефон | Облачный агент |
| Автоудаление расшифровок через N дней | Правило Тиць: удаляет только человек |
| Не записывать меня, пока я выключил микрофон в Meet | Нужно расширение браузера, выигрыш мал |
| Горячий угол экрана, вибрация трекпада, сдвиг окна на время созвона | Узко и только для Mac |
