# План: функции по примеру Aissia (2026-11-09, урезан 2026-11-09)

Запрос владельца: исправление на лету; панель быстрого доступа; расшифровка во время созвона; заметки к созвону; отдельное окно созвонов; быстрая расшифровка на Mac.

Источники: разбор `Aissia.dmg` 1.0.23 (файлы и тексты, программа не запускалась) и код Tyts на коммите `aed8a14`. Всё локально: без облака, без аккаунта.

**Правило этого плана:** каждый этап сначала опирается на то, что уже есть в Tyts. Новая модель, новый поток звука или новое окно появляются, только если существующее не справилось на замере.

## Что уже есть и чего нет

| Функция | У Tyts сейчас | Не хватает |
|---|---|---|
| Быстрая расшифровка на Mac | Parakeet кусками по паузам, FluidAudio для голосов, helper `speakers-mac`, модели с проверкой (`aed8a14`) | проверка на целом созвоне |
| Расшифровка во время созвона | движок **уже** распознаёт созвон кусками по 5 мин во время записи (`jobs.py _pieces`, `incoming/pieces-{track}.json`), диктовку пропускает вперёд | показать эти куски человеку; кусок покороче |
| Заметки к созвону | снимки экрана с временем, ручной снимок помечен `-m` (`SHOT_NAME`), снимки идут в итог | текстовые заметки |
| Окно созвонов | страница «Расшифровки» в окне приложения; шаблоны итога (4 готовых + один свой) | отдельное окно, вкладки, свои шаблоны списком |
| Панель быстрого доступа | панель по значку в трее / строке меню (`webview/tray.ts`) | показ у верхнего края, ряд кнопок с карточками |
| Исправление на лету | раскладка, две заглавные, Caps Lock, обучение (`typist.ts`, `learning.ts`); на Mac перехват не проверен | опечатки, заглавная после точки, «ё», «Вычитать» |

## Решения владельца

1. Расшифровка во время созвона — делаем сейчас, сначала на Mac (запрос 2026-11-09).
2. История буфера — не берём (2026-10-29, есть Win+V).
3. «Вычитать» — маленькая модель пунктуации, не большая (2026-11-09).
4. «Не давать Маку засыпать» — не берём, в запросе нет.

## Этапы

### Этап 0. Проверить быструю расшифровку на Mac
- Код готов. Осталось: сегодняшний созвон (1 ч 58 мин) целиком на копии, цель — меньше 20 минут.

### Этап 1. Живые строки созвона (на готовых кусках)
- Кусок не 5 минут, а около 30 с (`PIECE` в `jobs.py`; цикл воркера чаще 30 с, пока идёт запись). Сначала замер нагрузки на M1: если 30 с слишком часто, берём 60.
- Движок отдаёт готовые куски: `GET /recordings/{id}/pieces` читает `pieces-{track}.json` (`read_pieces` уже проверяет файл).
- Страница записи и страница созвона раз в несколько секунд спрашивают этот адрес и показывают строки («я» — микрофон, «они» — звук компьютера).
- После «Стоп» ничего нового: конец уже берёт готовые куски и досчитывает остаток.
- Ресурсы: строка в контракте (`docs/backlog.md`) — Parakeet на процессоре, пока идёт запись.
- Проверка: тест адреса на записанном звуке, замер на M1 за час.
- **Не делаем**: второй поток PCM со страницы записи, отдельные сессии в `stream.py`, скользящее окно. Добавим, если задержка в 30–60 с окажется мала для человека.

### Этап 2. Окно созвонов (решение владельца 2026-11-09: отдельное окно)
**Сделано 2026-11-09**: окно, список с поиском, вкладки Расшифровка · Заметки · Итог, свои шаблоны списком, заметки в поиске, экспорте и итоге. Не сделано: строка хранилища под списком, уведомление «Запись готова» с вкладками.
По образцу Aissia (скрин окна записей). Отдельное окно, как «Поговорить с уткой» (`createTalkWindow`); код страницы «Расшифровки» переезжает в него, вторая копия не появляется — в окне приложения остаётся ссылка «Открыть созвоны».
- **Слева**: поиск по записям, список всех созвонов (дата, длительность, идущий — первым и с точкой), внизу итог хранилища: «Созвонов: N · M МБ».
- **Справа, шапка**: название (правится карандашом), дата, длительность, «на этом компьютере»; кнопки «Копировать», «Удалить», «…» (экспорт, в базу знаний, расшифровать заново — то, что уже есть).
- **Вкладки**: «Расшифровка» · «Заметки» · «Итог». Сбоку панель «Говорящие · названо N из M» с полями имён (переименование уже есть, меняется только вид).
- **Итог**: выбор шаблона прямо во вкладке (общий, стендап, интервью, лекция — уже есть в `summary.ts`) и **свои шаблоны**: сейчас один `own`, станет список `summaryTemplates: [{name, text}]` в настройках, «+ Новый шаблон», правка и удаление. Каждый — до 500 знаков (`SUMMARY_OWN_MAX`).
- **Уведомление «Запись готова»** в углу после «Стоп», с теми же тремя вкладками: щелчок открывает окно на нужной.
- Открывается из панели (этап 4), с панели записи и по своей клавише.
- Проверка: тесты разрешений окна (`bridge.ts`), тест списка шаблонов в `settings.normalize` (старый `own` переносится первым шаблоном), ручная проверка на Mac и Windows.

### Этап 3. Заметки к созвону
- Вкладка «Заметки»: текстовое поле, сохраняется само. Во время записи — кнопка «Заметка» на панели записи, к ней ставится время от начала, как у снимка.
- В `transcript.json` поле `notes: [{at?, text}]`; `PATCH /transcripts` его принимает; поиск по записям ищет и в заметках; `summary.ts` кладёт заметки в подсказку итога, как текст со снимков.
- Заметки — текст человека: в журналы и отчёты не попадают.
- Проверка: тесты движка (сохранение, поиск, экспорт), тест подсказки итога.

### Этап 4. Панель у верхнего края (решение владельца 2026-11-09: как у Aissia)
**Сделано 2026-11-09**: показ у края, ряд кнопок с карточками (диктовка и последние фразы, созвоны, запись, быстрые переключатели), строка проблемы, переключатель в Параметрах. Не сделано: «Убрать с панели», быстрое действие.
По скринам Aissia: курсор задержался у верхнего края в середине экрана → под строкой меню выезжает узкая панель.
- **Строка состояния**: одна проблема, если есть («Скачайте модель распознавания» → «Параметры»).
- **Ряд кнопок**: Диктовка · Вставить последнюю · Быстрое действие · Созвоны (счётчик новых) · Запись; справа Сообщить о проблеме · Параметры · Выключить.
- **Наведение на кнопку раскрывает карточку под ней**: Созвоны — последние 3 и «Перейти к созвонам»; Запись — «Начать запись» / идущая запись; Параметры — 2–3 переключателя (исправление раскладки, меню выделения) и подсказки клавиш; у каждой карточки «Убрать с панели» (вернуть — в Параметрах).
- Включается в Параметрах; не появляется над полноэкранной программой; на Windows — та же панель по краю, плюс значок в трее как сейчас.
- Ресурсы: положение курсора спрашивается раз в 100 мс только в главном процессе (`screen.getCursorScreenPoint`), без перехвата мыши; строка в контракте ресурсов.
- Проверка: тесты логики края (задержка, полный экран, несколько мониторов, курсор ушёл), ручная проверка.

### Этап 5. Исправление на лету
- **Сначала**: проверить перехват клавиш на Mac на живой системе (`roadmap 0.7 #13`).
- **Заглавная после точки, «ё»**: правила в `Typist`, по переключателю. Тест на имитации поля.
- **Опечатки**: слово не из словаря (`media/layout/*.txt`), рядом одно частое на расстоянии одной правки → замена, как у раскладки. «Отменить» оставляет слово и запоминает его (`learning.ts`). Ложных срабатываний не больше, чем у раскладки, на наборе опечаток для ru и uk.
- **«Вычитать»**: клавиша и пункт меню; маленькая модель пунктуации; замена через `ClipboardGuard`; карточка изменений (`worddiff.ts`). Модель скачивается по согласию, с размером и SHA-256.
- **Не делаем**: запятые на лету (та же модель, но риск ложных правок при каждом наборе — «Вычитать» по клавише это закрывает) и вопрос «только в этой программе / везде» при каждой правке (выключение по программе уже есть в `AppRule`).

### Этап 6. Мелочи со скринов Aissia
- **Два разрешения на Mac при первом запуске**: Микрофон и Универсальный доступ, у каждого галочка, когда дано, и «Открыть настройки» для второго с подсказкой «включите Tyts в окне, которое открылось». Сейчас Tyts проверяет только микрофон, а без Универсального доступа клавиатура на Mac молчит.
- **Голоса других на Mac**: строка «Записывается только микрофон — разрешите запись экрана» с кнопкой «Разрешить».
- **«Вычитать»: пример «было → стало»** на странице, исправления подсвечены; переключатель «Заглавная в начале предложения».
- **Клавиши**: рисунок клавиатуры, назначенные клавиши подсвечены цветом своего действия.

### Чего у Aissia не берём
Аккаунт и Pro, заметки и итог в облаке, «Сэкономлено за месяц», «Не давать Маку засыпать», история буфера (решения выше). Автоудаление звука через 30 дней — только если владелец решит отдельно: сейчас правило «удаляет только человек».

## Правила везде

- Ничего не скачивается без спроса; загрузка проверяется по размеру и SHA-256.
- Каждая новая функция — строка в контракте ресурсов.
- Текст человека не теряется и не попадает в журналы.
- Windows не ломаем: где функция только для Mac, на Windows всё как раньше.
